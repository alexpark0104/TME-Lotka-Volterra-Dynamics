# Project Rework in Progress

This repository is currently being reworked from the ground up.

The existing code is an exploratory prototype for a phenomenological tumor–immune–Treg ODE model. It is being retained as a reference while the project is rebuilt with clearer scientific assumptions, verified data sources, consistent equations and implementation, reproducible analyses, and stronger validation practices.

During the rework:

- The model equations and Python implementation will be reconciled.
- Parameter units, interpretation, and provenance will be documented.
- Synthetic parameter recovery will be separated from biological model fitting.
- External datasets and citations will be independently verified.
- Validation will use data that are separate from the fitting data where possible.
- Sensitivity analysis, uncertainty estimates, and reproducible figures will be added.
- Runtime errors, tests, and installation instructions will be addressed.

The current results should not be interpreted as clinically predictive or as quantitative biological validation. Updated results will replace the exploratory implementation as the rework progresses.
